# Deck

> 0.4.0：接通 Deck 后台准备、用户确认提交、生成状态轮询、结果预览和逐个文件另存为。

Deck 是一个本地 Dola 多账号图片/视频创作台，并保留本地文件管理和用户有权编辑的视频清理能力。

## 当前功能

- Deck 前台提供独立的图片/视频生成控制台；Dola 会话默认在后台保持，不把 Dola 网页作为主界面展示。
- 账号栏、提示词、素材、参数和任务队列已经合并进同一个工作台，切换账号后仍留在当前工作流。
- 生成台支持素材别名和 `@` 引用；图片从本地加入后默认按文件名生成别名，并把它填入提示词中预先写好的 `@` 占位符（如 `参考角色：@` → `参考角色：@西门孝`），也可以关闭自动填入。
- 生成台支持提示词预检、任务草稿，以及按生成类型切换真实核验过的模型、画幅、时长和图片风格。
- 额度卡按账号读取 Dola 页面中的剩余积分/用量，连接后自动读取、每分钟后台刷新，也可以手动刷新；若页面结构变化会明确显示“页面未识别”，不会伪造额度。
- “检查并准备生成”会把模式、模型、画幅、时长、提示词和本地参考图写入后台 Dola 页面，但不会扣额度；任务卡再次点击“确认生成”后才真正提交。
- 提交后 Deck 每 5 秒读取一次生成状态，完成结果直接显示在任务卡中；每个结果的“选择位置保存”都会单独打开系统保存窗口。
- 当前页面核验到的视频参数：Dreamina Seedance 2.5 / 2.0 Fast / 1.0，5 秒或 10 秒，1:1、3:4、4:3、9:16、16:9、21:9；视频上传控件当前只接受图片参考。
- 当前页面核验到的图片参数：Seedream 4.5 / 5.0 Pro，1:1、2:3、3:4、4:3、9:16、16:9，以及 Dola 的图片风格选项；Deck 另提供 21:9 目标画幅，当前 Dola 图片页未显示原生 21:9，提交适配仍待完成。
- 音频可以先加入 Deck 素材清单，但当前 Dola 生成页没有音频上传控件，自动提交前会阻止误传；后续单独适配。
- 每个账号使用独立持久会话，可自由切换；登录由 Dola 页面完成，Deck 不读取密码、Cookie 或令牌。
- 内置 Dola 下载由 Deck 接管，可在每个文件下载前单独询问保存位置。
- Chrome / Edge 独立浏览器环境仍保留，作为外部打开方式。
- 快速角标模式：手动框选固定小区域，使用 FFmpeg `delogo`。
- AI 清理模式：VideoWipe OCR 检测、预览确认、STTN 时序修复，并使用 DirectML 调用本机 GPU。
- 支持导入自己的视频；原文件不覆盖；处理后使用 FFprobe 验证视频流和音频流。
- 已检测到本机豆包桌面应用，但它并非已确认支持独立配置目录的浏览器，因此暂不用于多账号启动。

## 运行

```powershell
npm install
npm start
```

默认数据目录是 Windows 下的 `D:\DeckData`（没有 D 盘时回退到用户应用数据目录）。首次连接某个账号时仍需要在对应会话完成 Dola 登录；生成台的前台操作不会显示 Dola 网页。准备阶段不扣额度，只有任务卡中的“确认生成”会真正提交。

FFmpeg / FFprobe 默认从系统 `PATH` 查找，也可以通过 `DECK_FFMPEG_DIR` 指向二进制目录。豆包桌面端的自定义位置可以通过 `DECK_DOUBAO_PATH` 指定。

本机 AI 运行环境位于 `D:\DeckData\engines\videowipe-env`，模型位于 `D:\DeckData\engines\videowipe-weights`。它们不打进 Deck 安装包，也不修改其他 Python 环境。

## 测试与打包

```powershell
npm run check
npm test
npm run test:media
npm run dist
```

构建产物位于 `release`。`test:media` 会生成临时测试视频、执行真实去水印流程、验证视频与音频流，然后清理临时文件。

## 已知边界

- Deck 不绕过登录验证、验证码或平台限制。
- Dola 的具体图片/视频模型、额度和生成能力由 Dola 当前网页提供，Deck 不绕过平台限制。
- 快速模式仅适合固定小角标；硬字幕和文字水印应走 AI 模式，并先检查检测预览。
- AI 修复不是像素恢复：永久遮挡、快速运动和复杂纹理仍可能出现合成痕迹。
- 仅处理你拥有或获准编辑的内容。

## 第三方引擎

AI 清理调用本机独立安装的 [VideoWipe](https://github.com/KKenny0/videowipe) 0.9.0（GPL-3.0）。第三方源码、模型和 Python 环境不提交到本仓库，也不打入 Deck 安装包；Deck 通过独立进程调用它。
